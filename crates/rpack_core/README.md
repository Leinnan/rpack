# rpack_core

Atlas packing, configuration and data types shared by the rpack tools:
[`bevy_rpack`](https://crates.io/crates/bevy_rpack),
[`rpack_cli`](https://crates.io/crates/rpack_cli) and
[`rpack_egui`](https://crates.io/crates/rpack_egui).

It has no UI dependencies, and it depends on Bevy only through the optional `bevy` feature.
